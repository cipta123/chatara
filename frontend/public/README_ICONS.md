# PWA Icons

Untuk membuat aplikasi PWA yang bisa diinstall, Anda perlu membuat 2 icon:

1. **icon-192.png** - 192x192 pixels
2. **icon-512.png** - 512x512 pixels

## Cara membuat icon:

### Option 1: Online Tools
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/

### Option 2: Manual
1. Buat logo/icon dengan ukuran minimal 512x512px
2. Export sebagai PNG
3. Resize ke 192x192 untuk icon-192.png
4. Copy ke 512x512 untuk icon-512.png
5. Simpan di folder `frontend/public/`

## Icon Requirements:
- Format: PNG
- Background: Transparent atau solid color
- Recommended: Square icon dengan padding (tidak full edge-to-edge)

Setelah icon dibuat, aplikasi akan bisa diinstall sebagai PWA di Android/iOS.
